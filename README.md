# Film Burn

Warm light bleeding in from the frame edges, breathing slowly — the burnt-film transition look, running continuously.

An [azphalt](https://github.com/HereLiesAz/azphalt) extension for
[Guillotine](https://github.com/HereLiesAz/Guillotine).

- **Package id** — `com.hereliesaz.azphalt.film-burn`
- **Version** — 1.0.0
- **Kind** — asset (ISF fragment shader)
- **Tags** — `shader`, `stylize`, `film-burn`, `light-leak`, `analog`, `transition`, `one-click`

## Controls

| Parameter | Label | Range | Default |
| --- | --- | --- | --- |
| `intensity` | Intensity | 0.0 – 1.0 | 0.55 |
| `speed` | Breathe speed | 0.02 – 1.0 | 0.2 |

## Install

Open **Azphalt Store** inside Guillotine, find *Film Burn*, and tap **Install**. The effect is
applied to the selected clip.

To install manually, pack this directory as a `.azp` (a plain ZIP with `manifest.json` at the root)
and side-load it from the store's *Install from file* action.
